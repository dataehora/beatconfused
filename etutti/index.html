Setting up the Teensy
  1. Mount the Audio Board on the Teensy (Rev D for Teensy 4.x) and plug headphones or an amplifier into its output.
  2. Install Arduino IDE with Teensyduino, open the etutti_synth sketch from this site's repository, and choose your board under Tools › Board.
  3. Under Tools › USB Type choose "MIDI" (or "Serial + MIDI"), then upload.
  4. Plug the Teensy into this computer, press Connect above and allow MIDI access. Use Chrome or Edge; Safari has no Web MIDI.
