# eTutti Slim

Versão de 32 teclas, a mais fina possível, independente do Student V4.

- `SPEC.md` — especificação vigente (R1SL). Comece por aqui.
- `conceito/` — material do conceito feito no Chat: renders, cortes, plantas, desenho dos knobs e scripts que geraram tudo.
- `fornecimento/gateron/` — desenho oficial e STEP do switch KS‑33D.
- Pastas que o Code vai criar: `pcb/` (KiCad), `case/`, `firmware/` e os relatórios `ELETRONICA.md`, `FIRMWARE.md`, `POSICIONAMENTO.md`, `ROTEAMENTO.md` e `FIT_CHECK.md`.

Etapas: 1) componentes e lógica → portão A · 2) posicionamento (régua e placa principal em sessões separadas) → portão B · 3) roteamento (idem) → portão C.
